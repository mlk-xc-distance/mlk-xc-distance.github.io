Tabata Core

Printable PDF version →

A quick, high-intensity core workout using the Tabata interval format.

A tabata time structure is 20 seconds of work and 10 seconds of rest, for 8 rounds — 4 minutes total. Each one is a superset: pick two exercises and alternate between them each round.
